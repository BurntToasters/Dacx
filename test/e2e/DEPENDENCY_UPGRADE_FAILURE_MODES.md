# Dependency upgrade (tray_manager 0.8, desktop_drop 0.9) failure inventory

Acceptance boundary for upgrading `tray_manager` to `^0.8.0` (moves to
`nativeapi ^0.5.1`) and `desktop_drop` to `^0.9.1`. `dbus` stays `^0.7.15`
because `anni_mpris_service` 0.1.0 requires `dbus ^0.7.6`. Each case names
how it is proven: `E2E` = `test/e2e/dependency_upgrade_e2e_test.dart` (or an
existing E2E test it points to), `BUILD` = `flutter build macos --release`
or `pub deps` output, `SMOKE` = the real-player macOS smoke run,
`MANUAL` = needs a real Windows/Linux desktop and is verified only by CI or
a later manual pass.

Tray (tray_manager 0.8 / nativeapi 0.5):

- The tray icon or its menu is not created on a supported platform, but
  `init` reports success. Proof: E2E asserts `isInitialized` is false when
  native handles cannot be created, and that `init` never throws. Real native
  creation: SMOKE/MANUAL.
- Show and Quit labels are not applied at first `init`. Proof: MANUAL on
  macOS tray menu (SMOKE does not open the tray menu).
- Show and Quit labels are not updated after locale load (second `init`
  with new labels). Proof: MANUAL; E2E asserts the second `init` path
  does not throw and does not create a second native tray.
- Quit does not invoke the `onQuit` callback. Proof: MANUAL (native click
  required); E2E confirms the callback wiring is compile-checked through
  the `TrayService` surface.
- Hide-to-tray does not hide, or restore does not show the window. Proof:
  E2E covers the fallback where tray is unavailable (minimize, never hide);
  the hide/show branch is MANUAL.
- Tray dispose leaks native handles. Proof: E2E calls `dispose` on a
  never-initialized service and after a failed `init`; both must complete
  and leave `isInitialized` false. Native leak check: MANUAL.
- Tray dispose double-disposes (a second `dispose` touches freed handles).
  Proof: E2E calls `dispose` twice; no exception, no state change.
- `init` called twice creates two trays or two menus. Proof: E2E calls
  `init` twice on an unsupported/failed tray and asserts no throw and
  `isInitialized` false; the single-tray guarantee is MANUAL.
- `hideToTray` after a failed tray calls `hide` instead of `minimize`.
  Proof: E2E (existing `audit6` tray group also covers this).
- Native dylib missing in the test host makes `init` throw instead of
  being caught. Proof: E2E, because `init` must swallow the failure.

Drag and drop (desktop_drop 0.9):

- Dropping files does not reach `_applyDroppedPaths`. Proof: E2E drives
  `initialDropPaths` (the same entry point `DropTarget.onDragDone` calls)
  with real media files and asserts `openCalls`.
- Dropping a folder does not expand to its media. Proof: E2E with a real
  temp folder containing supported media.
- Dropping a playlist (`.m3u`) does not parse into queued entries. Proof:
  E2E with a real temp `.m3u` file.
- Dropping a non-local item (http/https URL) is treated as a file path or
  dropped. Proof: E2E with an `https://` path.
- Dropping an unsafe or empty path is opened. Proof: existing
  `player_screen_pump_test.dart` invalid/mixed drop cases; E2E repeats one
  empty/unsafe case.
- `DropTarget` callbacks (`onDragEntered`, `onDragExited`, `onDragDone`)
  no longer fire, or `DropDoneDetails.files` changes shape (path property).
  Proof: BUILD (compile against the 0.9 API) and MANUAL for live drag from
  Finder/Explorer/file manager.

Native and build:

- `dbus` resolves to 0.8 and breaks Linux MPRIS (`anni_mpris_service`
  requires `^0.7.6`). Proof: BUILD (`pub deps` must show `dbus 0.7.x`).
- Generated plugin registrants (macOS `GeneratedPluginRegistrant.swift`,
  Windows and Linux `generated_plugins.cmake`) are missing or stale after
  `pub get`. Proof: BUILD (`flutter build macos` regenerates and links);
  Windows and Linux registrants are regenerated by `pub get` and
  verified by CI (MANUAL here).
- macOS release build fails to link (new nativeapi or desktop_drop native
  pods). Proof: BUILD (`flutter build macos --release`).
- Real-player playback regresses on macOS. Proof: SMOKE
  (`run-mac-e2e.sh`).
